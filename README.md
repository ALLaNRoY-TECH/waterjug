# WaterJug

## Overview

WaterJug is an interactive web application designed to visualize and solve the classic Water Jug Problem. The platform helps users understand state-space search and problem-solving algorithms by providing step-by-step solutions and visual representations of the process.

The project demonstrates how Artificial Intelligence search techniques can be applied to solve real-world logical problems efficiently.

## Features

* Interactive Water Jug Problem solver
* Step-by-step solution visualization
* User-defined jug capacities and target volume
* State-space exploration and tracking
* Visual representation of each operation
* Responsive and user-friendly interface
* Instant solution generation

## How It Works

1. Users enter the capacities of the two water jugs.
2. Users specify the target amount of water.
3. The system explores possible states and operations.
4. A valid sequence of steps is generated to reach the target.
5. The solution is displayed visually for easier understanding.
